# 雷达 · Android

面向三星 Galaxy A17 港版的独立音乐发现应用。Kotlin / Jetpack Compose，Android 8.0+，发布 APK 包含 arm64-v8a 本地推理运行时。

功能：网易云手机验证码／二维码登录；先选择歌单再开始分析；完整读取所选歌单的歌曲资料；每日推荐与历史去重；熟悉歌手排除、同歌手及同专辑配额；14 个独立推荐权重；11 个偏好维度与不喜欢类型筛选；本地分析档案；指定网易云歌单收藏；Media3 通知栏、锁屏、后台播放；同步歌词；可调色调、深浅模式与三种材质。

## 构建

需要 JDK 17、Android SDK 35 / build-tools 35.0.0、Gradle 8.11.1。

    gradle testDebugUnitTest lintRelease assembleRelease

release 输出未签名 APK，由项目所有者使用持久化的签名密钥签名。签名密钥、密码和用户账号资料不得提交到仓库。签名之后覆盖升级，账号及音乐资料保留。发布目录为原仓库的 android/，版本标签为 android-v*；安卓发布不能修改 Windows 的 latest 发布或 latest.yml。

## 运行与数据

- 第一次登录不会自动分析。选择分析源和自己的收藏目标，然后点击开始分析。
- Cookie 使用 Android Keystore / AES-GCM 加密，其他分析资料使用 app 私有目录中的 AtomicFile。关闭系统备份，不记录请求头、Cookie、手机号或验证码。
- 仅使用网易云返回的资源与账号权限；无解锁付费资源或第三方音源。
- 乐器识别为音频分类，非专业乐器转录。AST 量化模型约 91 MB，首次使用独立下载、SHA-256 校验及断点续传。仅 Wi-Fi 的选项同时限制模型下载与音频分析。模型缺失时仍可读取歌单、分析歌词和推荐。
- 节奏、音色、动态和音高分布为本地信号估计。缺失特征不会捏造，也不会提高歌手权重。歌手相同不计分，默认过滤分析源中已有的歌手。
- WorkManager 每小时检查是否应生成当天歌单；系统省电可能推迟后台任务。打开软件也会补检查。不会为了凑数量重复填充历史歌曲。
- 歌词和音频分析按预算逐轮进行，完成的结果保留在档案中，暂停后可继续。

## 更新协议

android/update.json 提供 versionCode、versionName、签名 APK 的 GitHub Release URL 和 SHA-256。应用验证下载摘要、包名和当前证书，用户经系统安装界面确认覆盖更新。没有静默安装或 Root 要求。

## 验证范围

算法、历史去重、配额、筛选、歌词时间戳、加密协议和信号 FFT 使用 JVM 测试验证。匿名歌曲资料和歌词接口以真实网络请求核对。短信发送、账号登录、会员播放与收藏写入需要项目所有者在手机上进行实机确认，不能通过模拟点击声称这些环节已经成功。
