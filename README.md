# 雷达 1.2

Windows 10/11 x64 的网易云音乐发现助手。安装包含播放器、推荐引擎与本地音频模型，不需要另装运行环境或搭服务器。

## 使用

1. 双击 MusicCompass-Setup-1.2.0.exe。已有 1.0 / 1.1 的用户直接覆盖安装，不用卸载；账号、历史和本地资料保留。
2. 用手机网易云音乐扫码连接，在设置中读取歌单。
3. 勾选想用于分析的歌单，并指定爱心收藏写入的个人歌单。喜欢列表和近期排行只有明确勾选才参与分析。
4. 在“待分析的歌单”区点击“开始分析”。仅保存设置不会自动启动首次分析。
5. 歌曲旁的播放键直接在软件中播放；爱心写入指定网易云歌单，再次点击会移除。网络操作失败不会显示成功。
6. 在设置里开启顶部 / 气泡播放器并保存。默认显示在屏幕顶部；拖住“⠿ 雷达”移到其他位置变成气泡，鼠标移入或点击展开，拖回顶部或点击 ⌃ 恢复顶部播放器。支持播放/暂停、上一首/下一首、随机/顺序、进度、时长、爱心与打开主窗口。

首次运行和来源变更后都要手动开始分析。之后软件运行期间，在指定时间生成每日歌单；关机期间不会运行。默认不随 Windows 启动。开启悬浮播放器或后台运行后，关闭主窗口会缩到托盘，托盘菜单可以退出。

## 推荐与音频分析

指定歌单读取完整歌曲 ID 和资料，没有旧版每歌单 200 首、喜欢列表 300 首的分析上限。候选扩展以最多 40 首种子及关联歌单、风格标签和可获取的每日推荐为依据；歌词首轮覆盖最多 40 首种子和 160 首候选。“继续分析”会处理余下来源歌曲的歌词和音频，结果缓存在本地。

默认不给歌手相同加分，并排除分析来源里出现过的歌手；每份推荐同歌手最多一首。同专辑、已收藏、近期推荐、不感兴趣及重复版本也参与筛选。关闭“避开熟悉的歌手”后才允许来源歌手进入候选。候选不足时显示实际数量。

可用因素包括歌曲关联、歌单风格、歌词情绪/主题/语言、年代、时长、反馈，以及真实音频里的乐器、人声、速度、频谱音色、音高分布和动态。可分别调整 14 个推荐因素的相对权重、7/14/30/60 天推荐去重、同歌手和同专辑数量，以及每轮 12/24/48/72 首的分析预算。默认每轮识别 24 首音频，首轮分给来源和候选，其后分批补齐。继续分析的歌词数量也按该预算分批处理。软件运行期间约每 10 分钟继续补充来源特征；也可点击“继续分析”。缺失音源不会编造特征。

乐器使用 AST AudioSet 量化模型本地估计，多段抽样取高置信结果，支持钢琴、吉他、弦乐、管乐、合成器和打击乐等。它不是专业乐谱转录；混音、电子音色、短试听可能误判。节奏为粗估 BPM，频谱和音高分布并非准确曲风或调性标签。歌词关键词和歌单标签是弱线索。所有分数是匹配规则，不是喜欢概率。

网易云接入为第三方组件 @neteasecloudmusicapienhanced/api 4.40.0。播放和分析只使用网易云返回的授权音源，不解除版权或会员限制；试听音源会显示提示。收藏需要账号仍有效、目标歌单可写且接口可用。

## 更新

已配置公开仓库 https://github.com/XZI-Y/music-detecter 的正式 Releases 作为更新来源。启动两分钟后、其后每四小时检查更新；自动更新开启时下载完成后提示重启安装。更新不会在播放途中强制重启。设置里也可以手动检查。

仓库需有正式 Release，且同时上传 MusicCompass-Setup-版本.exe、同名 .exe.blockmap、latest.yml。仅上传源码或仅上传 exe 不能启用自动更新。更新检查和下载需要电脑可以正常访问 GitHub。请勿在聊天或源码中放访问令牌。

1.0 没有更新器，因此升级到新版本需覆盖安装一次。之后的新版本只要正确发布上述文件，便可在软件内下载安装。

## 偏好统计

独立的“偏好统计”页展示风格、乐器、节奏速度、音色、人声、强弱变化、歌词语言/情绪/主题、年代及歌曲时长。每项显示有效样本、缺失数量、歌曲数和占比；占比以有该特征的来源歌曲为分母，多标签歌曲可以归入多项。音频结果是估计，分布不等同于喜欢概率。

可切换当前歌单和历次分析记录，查看分析时间，并导出统计 JSON。来源歌曲的特征持续保存在本地，换歌单和重启不会清除；任务停止或失败时，已经完成的来源特征也会保存。未识别的内容保持缺失，不编造结果。清除数据或切换账号才会移除当前账号的本地资料。

## 数据与验证

继续使用旧版的用户应用数据目录“听见新喜欢”，避免更名造成资料丢失；其中保存 library.json、audio-cache.json、lyric-cache.json 和 account.bin。登录凭据通过 Windows DPAPI 加密，不能解密时要求重新连接，不保存明文。退出连接保留历史；清除数据需再次确认。切换账号会隔离上一账号资料。覆盖升级保留本地资料，卸载也默认保留。

已测试推荐排除、完整大歌单读取、缺失因素、收藏接口响应、存储、快速切歌、随机播放、页面控件、真实公共音源播放与本地模型推理。真实账号扫码、个人收藏写入需由账号本人验证。工具环境下的桌面测试使用隔离目录和仅测试时开启的兼容参数；日常运行保持 Electron 沙箱。此个人测试版尚未进行商业代码签名。

## 开发

Node.js 22+、pnpm 10：

```text
pnpm install --frozen-lockfile
node node_modules/electron/install.js
node tools/download-model.mjs
pnpm test
pnpm start
pnpm exec electron-builder --win nsis --x64 --publish never
```

模型下载固定版本并校验 ONNX SHA256。安装包已含模型，普通用户不需要执行上述命令。

源码含 .github/workflows/release.yml：手动运行只构建并保存发布文件；推送与 package.json 相符的 v版本标签会构建并发布正式 Release。请先更新 package.json 版本，不要覆盖已经使用的版本号。
